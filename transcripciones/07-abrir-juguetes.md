HABI [0.9s]: ¡Síííí, Timi! ¡Claro que puedes abrir el azul! Mira, para abrirlo, primero tenemos que encontrar la palabra mágica. Este juguete azul es una "BOX". ¿Puedes decir "BOX" después de mí?
NENE: Booooox. ¿Qué hay adentro?
HABI [0.7s]: ¡Perfecto, Timi! ¡Dijiste "BOX" genial! Ahora, para descubrir qué hay adentro, tenemos que decir la palabra mágica "OPEN". ¡Es como una llave! ¿Puedes decir "OPEN" después de mí?
NENE: O-pen. ¡Quiero abrirlo!
HABI [0.7s]: ¡Muy bien, Timi! ¡"OPEN"! ¡Lo hiciste! Ahora sí, con la palabra mágica "OPEN", podemos abrir la "BOX" azul. ¡A ver, ábrela! ¡Qué emoción!
NENE: *lo abre con dificultad* ¡Es un... un robot! ¡Mira Habi!

**Notas:** BOX → OPEN como "palabras mágicas" del juego. La acción (abrir) es parte
del cuento, no un pedido físico que el coach no pueda ver — el chico narra lo que pasa.
