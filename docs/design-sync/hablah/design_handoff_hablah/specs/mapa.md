# Mapa de progreso

## Purpose
Ver el recorrido: niveles, lo conquistado y lo que falta.

## Layout
Camino vertical de niveles (A0 → C1). Cada nivel es una card con estado (completado / actual / bloqueado), % de avance, gramática objetivo y las misiones que lo componen. El nivel actual se expande mostrando las misiones abiertas con su barra de 5 segmentos.

Sidebar derecha: resumen de misiones abiertas, vocabulario acumulado y minutos hablados.

## Notas
El bloqueo nunca es duro: un nivel "bloqueado" se puede probar igual, con una advertencia de que va a exigir más.
