# Perfil

## Purpose
Intereses, tutor activo y preferencias de práctica.

## Layout
1. **Intereses** — chips ordenables por preferencia; alimentan el orden de la grilla de Practicar.
2. **Tutor activo** — cards de personalidades con su rigurosidad (1-5) y si interrumpe o no; una seleccionada.
3. **Preferencias** — duración por defecto, ritmo por defecto, recordatorios.
4. **Cuenta** — plan, idioma de interfaz, datos.

## Notas
Cambiar el tutor no reinicia el progreso; se avisa que cambia el tono, no el nivel.
