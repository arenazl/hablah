# Historial

## Purpose
Todas las sesiones con su resultado, filtrables.

## Layout
Barra de filtros (rango de fecha, tópico, tutor, con/sin misión) + tabla de sesiones: fecha, tópico, tutor, duración, errores nuevos, misiones tocadas. Click abre el reporte de esa sesión.

Arriba, tira de KPIs del período: sesiones, minutos, errores cerrados, racha más larga.
